# 🚀 Inicio Rápido

Si ya tienes todo instalado y solo quieres iniciar el sistema:

## Windows

```bash
npm run dev
```

## Linux/Raspberry Pi

```bash
npm run dev
```

El sistema iniciará en:
- **Frontend**: http://localhost:5173
- **Backend/API**: http://localhost:3001

## Primera vez

Si es la primera vez, ejecuta:

### Windows
```bash
setup.bat
```

### Linux/Raspberry Pi
```bash
chmod +x setup.sh
./setup.sh
```

Luego edita `sync.config.js` con la configuración de tu backend y ejecuta `npm run dev`.
